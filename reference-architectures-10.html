Most Couchbase Mobile apps sync devices straight to the cloud, and the first tab shows that pattern. The other tabs show when a location needs its own edge tier, and what changes when it does.

Choosing the edge tier

No edge tier: most appsDevices run Couchbase Lite and sync straight to Sync Gateway or Capella App Services. Add peer-to-peer sync only when devices need to share data with each other offline.
Edge ServerOne site with a modest number of devices that has to keep working as a group when its cloud link drops, such as a store, a bank branch, or an aircraft. It syncs with Sync Gateway in the cloud.
Couchbase Server and Sync GatewayA large site with heavy traffic, many devices, or days of data to hold, such as an airport hub, a plant, or a ship. It syncs with the cloud through ISGR.
